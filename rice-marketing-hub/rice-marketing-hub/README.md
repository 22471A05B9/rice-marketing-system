# Rice Marketing Hub

A small Angular app where farmers list rice and buyers browse, filter and mark enquiries.

## Features
- Listing cards (variety, price per kg, stock)
- Search by farmer or village, filter by variety
- Enquiry toggle with a counter
- Add a new listing (validated form)

## Limits
Sample data only. Listings and enquiries live in memory and reset on refresh. There is no backend or database yet.

## Run
```
npm install
npm start
```
Open http://localhost:4200

## Tech
Angular 17 (standalone components, signals), TypeScript, CSS.
